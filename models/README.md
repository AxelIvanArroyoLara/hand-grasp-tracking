# Modelo local

`python -m scripts.setup` descarga Hand Landmarker float16 versión 1 desde Google y verifica el SHA-256.
El peso se conserva fuera de Git y del ZIP. Tras instalarlo y verificarlo, la inferencia funciona sin red.
[Guía y modelo de Google](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker/python)
